# Glosario de Dominio — Calculadora GRASP

| Término | Definición |
|---------|------------|
| Operando | Número sobre el cual se aplica una operación aritmética. |
| Operador | Símbolo que indica la operación a realizar: `+`, `-`, `*` o `/`. |
| Resultado | Valor obtenido al aplicar un operador sobre dos operandos. |
| Consola | Interfaz de usuario que lee entradas y muestra salidas por terminal. |
| Controlador | Objeto que recibe una operación de la UI y la coordina con la lógica de cálculo (GRASP Controller). |
| Calculadora | Clase experta en información que conoce los operandos y ejecuta el cálculo (GRASP Information Expert). |
| División por cero | Intento de dividir un número entre cero, operación indefinida que el sistema rechaza con un error. |
| Bajo acoplamiento | Grado bajo de dependencia entre clases; cambios en una no afectan a las otras. |
