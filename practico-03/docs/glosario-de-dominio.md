# Glosario de Dominio

| Término | Definición | Contexto |
|---|---|---|
| **GUI** | Graphical User Interface — interfaz gráfica que permite al usuario interactuar con el sistema mediante ventanas, botones y otros elementos visuales | 3.1, 3.2, 3.3 |
| **Widget** | Componente visual de una GUI (botón, etiqueta, campo de texto, etc.) | 1.4 |
| **Tkinter** | Biblioteca estándar de Python para crear interfaces gráficas basada en Tk | 1.1–1.9 |
| **ttk** | Submódulo de Tkinter con widgets temáticos (Themed Tk) que se integran mejor al aspecto nativo del SO | 1.3 |
| **Geometry Manager** | Método que controla la posición y tamaño de los widgets dentro de un contenedor: `pack`, `grid`, `place` | 1.8 |
| **Event Binding** | Mecanismo de Tkinter que asocia una función (callback) a un evento del usuario (clic, tecla, foco) mediante el método `bind()` | 1.9 |
| **Notebook** | Widget de Tkinter/ttk que organiza múltiples paneles en pestañas (tabs) | 1.5 |
| **SQLite** | Motor de base de datos SQL embebido, liviano, sin servidor, que se integra con Python mediante el módulo `sqlite3` | 2.1–2.7 |
| **CRUD** | Acrónimo de Create, Read, Update, Delete — operaciones básicas sobre una base de datos | 3.2 |
| **Repair Center** | Sistema de gestión de pedidos de servicio técnico con registro de cliente, dirección, inconveniente, técnico y visita | 3.2 |
| **Login** | Pantalla de autenticación que valida usuario y contraseña para acceder al sistema | 3.3 |
| **Treeview** | Widget de ttk que muestra datos en formato tabular (filas y columnas), usado para listar pedidos | 3.2 |
