# Registro de Necesidades — Práctica 01 Python OOP

## Formato
`RN-NNN: [Actor] debe/necesita [acción] para [motivo].`

## Lista de necesidades

| ID | Descripción | Consigna | Prioridad |
|----|-------------|----------|-----------|
| RN-001 | El sistema debe definir una clase con atributos de clase y de instancia. | 1.7, 1.8 | Alta |
| RN-002 | El sistema debe implementar métodos de instancia, de clase y estáticos. | 1.9 | Alta |
| RN-003 | El sistema debe proveer una calculadora que consuma los métodos anteriores. | 1.10 | Alta |
| RN-004 | El sistema debe implementar una jerarquía de herencia con clase base Animal y subclases Perro, Vaca, Abeja. | 2.1 | Alta |
| RN-005 | Cada subclase debe sobrescribir los métodos `hablar()` y `moverse()` de Animal. | 2.2 | Alta |
| RN-006 | El sistema debe demostrar el uso de `__bases__` y `__subclasses__()`. | 2.3 | Alta |
| RN-007 | El sistema debe demostrar el uso de `super()` para extender métodos de la clase padre. | 2.4 | Alta |
| RN-008 | El sistema debe crear objetos de cada subclase y mostrar sus comportamientos por consola. | 2.5 | Alta |
| RN-009 | El sistema debe implementar `@property` en al menos dos métodos de alguna clase. | 3.1 | Alta |
| RN-010 | El sistema debe implementar encapsulamiento usando `_variable` o `__variable`. | 3.2 | Alta |
| RN-011 | El sistema debe implementar setters con `@<atributo>.setter`. | 3.3 | Alta |
| RN-012 | El sistema debe permitir refactorizar la app de herencia aplicando conceptos de encapsulamiento, abstracción, acoplamiento y cohesión. | 4.1 | Media |
| RN-013 | El sistema debe demostrar polimorfismo iterando sobre una colección de objetos que responden al mismo método. | 5.1 | Alta |
| RN-014 | El sistema debe implementar una interfaz abstracta (ABC) para drones. | 6.2 | Alta |
| RN-015 | La interfaz abstracta debe definir métodos para: despegar, aterrizar, acelerar, frenar, doblar derecha, doblar izquierda, sacar fotos. | 6.2 | Alta |
| RN-016 | El sistema debe implementar al menos 5 subtipos de dron: Tricóptero, Cuadricóptero, Hexacóptero, Octocóptero y Coaxial. | 6.1 | Alta |
| RN-017 | El sistema debe proveer un menú por consola para que el usuario pilote un dron seleccionado. | 6.2 | Media |
| RN-018 | El sistema debe demostrar Duck Typing creando una lista de animales con el mismo método `hablar()` e invocándolo en un bucle. | 7.1 | Alta |
