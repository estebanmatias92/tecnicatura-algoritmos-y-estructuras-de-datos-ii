# Registro de Necesidades (RN)

| ID | Descripción | Prioridad |
|---|---|---|
| RN-001 | El sistema debe permitir calcular un presupuesto base para un hotel. | Alta |
| RN-002 | El sistema debe permitir agregar características opcionales (piscina, desayuno, gimnasio, wifi) al alojamiento, cada una con su costo adicional. | Alta |
| RN-003 | El sistema debe aplicar el patrón Decorator para agregar características sin modificar la clase base. | Alta |
| RN-004 | El sistema debe ser extensible para soportar nuevos tipos de alojamiento (hostels, apartamentos) en el futuro sin afectar el código existente. | Alta |
| RN-005 | El sistema debe mostrar un presupuesto detallado con descripción y precio final por noche. | Media |
| RN-006 | El sistema debe demostrar el funcionamiento del Decorator mediante un menú interactivo o ejemplos precargados. | Media |
