# Glosario de Dominio — Saca Muela

Términos del dominio odontológico consensuados para el proyecto.

| Término | Definición |
| :--- | :--- |
| **Paciente** | Persona física que asiste al consultorio para recibir atención odontológica. |
| **DNI** | Documento Nacional de Identidad. Identificador unívoco del paciente en el sistema. |
| **Turno** | Cita programada que vincula a un paciente con un odontólogo en una fecha y hora determinadas. |
| **Odontólogo / Profesional** | Profesional de la salud dental que brinda la atención. |
| **Consultorio** | Establecimiento físico donde se brinda la atención odontológica. |
| **Historia Clínica** | Registro cronológico de la evolución del paciente, diagnósticos, procedimientos y observaciones clínicas. |
| **Tratamiento** | Conjunto de procedimientos odontológicos planificados para un paciente. |
| **Obra Social** | Entidad de cobertura médica que puede cubrir total o parcialmente los tratamientos. |
| **CRUD** | Acrónimo de Create, Read, Update, Delete — operaciones básicas de persistencia. |
| **DNI duplicado** | Situación de violación de regla de dominio en la que se intenta registrar un DNI ya existente. |
| **Baja lógica** | Eliminación no física: el registro se marca como inactivo pero se conserva en la base de datos. |
