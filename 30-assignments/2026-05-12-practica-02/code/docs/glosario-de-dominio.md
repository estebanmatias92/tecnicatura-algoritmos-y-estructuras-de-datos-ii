# Glosario de Dominio

## Python Estructurado — Práctica 02

| Término | Definición |
|---|---|
| **Consola interactiva (REPL)** | Entorno que lee, evalúa e imprime expresiones Python línea por línea. Útil para prototipado rápido. |
| **PIP** | (Pip Installs Packages) Gestor de paquetes oficial de Python. Descarga e instala paquetes desde PyPI. |
| **PyPI** | Python Package Index — repositorio oficial de paquetes Python. |
| **Entorno virtual (venv)** | Directorio aislado que contiene su propia instalación de Python y paquetes, evitando conflictos entre proyectos. |
| **Variable en Python** | Nombre que referencia un objeto en memoria. Python usa tipado dinámico: la variable no tiene tipo fijo, el objeto sí. |
| **Tupla** | Secuencia **inmutable** de elementos heterogéneos. Se define con paréntesis `()`. |
| **Lista** | Secuencia **mutable** de elementos heterogéneos. Se define con corchetes `[]`. |
| **Diccionario** | Colección **mutable** de pares clave-valor. Se define con llaves `{}`. |
| **Range** | Función que genera secuencias numéricas inmutables, usada típicamente en bucles `for`. |
| **Recursividad** | Técnica donde una función se llama a sí misma para resolver subproblemas más pequeños. |
| **Función Lambda** | Función anónima de una sola expresión, definida con `lambda args: expr`. |
| **Programación funcional** | Paradigma que trata la computación como evaluación de funciones matemáticas, evitando estado mutable y efectos secundarios. |
| **Map** | Función que aplica una transformación a cada elemento de un iterable, retornando un iterador. |
| **Filter** | Función que retorna los elementos de un iterable para los cuales una función predicado es verdadera. |
| **Reduce** | Función que acumula los elementos de un iterable aplicando una función binaria, retornando un único valor. |
| **Excepción** | Evento que interrumpe el flujo normal del programa ante un error. Se "lanza" con `raise` y se "captura" con `try/except`. |
| **Unittest** | Framework de testing unitario incluido en la biblioteca estándar de Python. |
| **setUp / tearDown** | Métodos ejecutados antes y después de cada test en unittest, usados para preparar y limpiar recursos. |
| **Módulo** | Archivo `.py` que define funciones, clases y variables reutilizables. |
| **Paquete** | Directorio que contiene un `__init__.py` y múltiples módulos, formando una jerarquía de namespaces. |
| **sys.path** | Lista de rutas donde Python busca módulos al importar. |
| **Open / Close** | Funciones para abrir y cerrar archivos. `open()` retorna un objeto archivo; `close()` libera el recurso. |
| **With** | Sentencia que maneja automáticamente el contexto (apertura/cierre) de recursos como archivos. |
