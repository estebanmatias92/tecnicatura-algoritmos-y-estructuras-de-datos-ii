# Requisitos - Practico 09 STL

## Funcionales

1. Ejercicio STL vector (inserción, rango, `find`, `erase`).
2. STL Vector & Iterator (mostrar contenido con iterador).
3. Implementar un Map (`empty`, aleatorio, asignación, `erase`, `lower/upper_bound`).
4. Unordered_map — conteo de palabras (frase Bjarne Stroustrup).

## No funcionales

- 1 ejecutable por consigna (`stl_vector`, `stl_iterator`, `stl_map`, `stl_unordered_map`).
- C++11, Makefile, layout completo (`docs/`, `include/`, `src/`, `obj/`).
