# Glosario de Dominio — STL (Unidad 04)

| Término | Definición | Contexto |
|---|---|---|
| **STL** | Standard Template Library; bibliotecas de plantillas C++ para algoritmos y estructuras. | Marco Teórico |
| **vector** | Contenedor secuencia dinámico; inserción amortizada O(1) al final. | Consigna 1 |
| **iterator** | Objeto que permite recorrer un contenedor; sintaxis `vector<T>::iterator`. | Consigna 2 |
| **map** | Asociativo ordenado por árbol balanceado; clave-valor ordenado. | Consigna 3 |
| **unordered_map** | Asociativo no ordenado (hash table); búsqueda O(1) promedio. | Consigna 4 |
| **lower_bound / upper_bound** | Iteradores al primer elemento no menor / mayor que la clave. | Consigna 3 |
